# 🤖 MuJoCo + LLM 실습 리포지토리  

본 리포지토리는 **MuJoCo 기반 로봇 시뮬레이션**, **경량화 LLM(VLA) 모델 실습** 프로젝트를 다루고 있습니다.

국민대학교 **Wireless Intelligent Technology Lab**에서 진행된
2025 동계 특강 *"From Simulation to Reality: VLA 모델로 제어하는 로봇팔"* 실습 자료를 기반으로 제작되었습니다.

## 프로젝트 개요

기존 Mujoco turtlebot3 모델에 다양한 센서를 추가해 지정한 동작을 수행시키는 것이 프로젝트의 주된 목표입니다.
**LiDAR(Rangefinder) 센서와 Wheel Encoder 센서**를 이용해서 전방 장애물을 감지하고, 자동으로 회피 방향을 결정하는 **탐색 로봇**을 구현했습니다.
또한, **LLM(Gemini)**과 연동하여 사용자에게 직접 명령을 받아 로봇을 제어하며, MuJoCo 환경에서 자율 주행 및 탐색 동작을 실험합니다.

## 시스템 구성

1️⃣ **LLM 기반 사용자 명령 수행** 
사용자는 LLM(Gemini)를 통해 로봇에게 인간의 언어로 명령을 내릴 수 있습니다.
ex) "계속 직진해."
해당 명령을 받으면 로봇은 직진을 유지함과 동시에 지속적으로 전방 물체와의 거리를 측정합니다.

2️⃣ **센서 기반 환경 인식**
• LiDAR(Rangefinder) -> 전방 장애물과의 거리 측정
• Wheel Encoder -> 바퀴 회전량을 기반으로 로봇의 회전 각도를 측정 -> 정확한 회전 제어 가능

3️⃣ **장애물 회피 알고리즘**
사용자 명령을 수행하던 로봇이 전방 1m 이내에 장애물을 감지하면, 자동으로 탐색 모드로 전환됩니다.
탐색 모드에 들어간 로봇은 다음 동작을 수행합니다.
1. 오른쪽으로 60도 회전 후 전방 거리 측정
2. 왼쪽으로 60도 회전 후 전방 거리 측정
3. 두 측정된 거리를 비교하여 다음 action 결정 -> 가능한 action: turn left(90), turn right(90), turn back(180)
   
동작을 마친 로봇은 다시 사용자의 명령을 이어서 수행합니다.

## 객체 인식 (YOLO)

로봇 전방 카메라 이미지 입력을 통해 4가지 과일을 구분 가능한 YOLO모델을 적용했습니다.
전방 카메라를 통해 보이는 사과, 바나나, 오렌지, 수박을 실시간으로 구별할 수 있습니다.

## 사용 기술
• **MuJoCo** - 로봇 물리 시뮬레이션
• **LLM (Gemini)** - 사용자 명령 인터페이스
• **YOLO** - 객체 인식
• **LiDAR(Rangefinder), Wheel Encoder 센서** - 환경 정보 추정 및 로봇 정밀 제어
