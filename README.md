# 🤖 MuJoCo + LLM 실습 리포지토리  

본 리포지토리는 **MuJoCo 기반 로봇 시뮬레이션**, **경량화 LLM(VLA) 모델 실습** 프로젝트에 대한 내용을 다루고 있습니다.

국민대학교 **Wireless Intelligent Technology Lab (WIT LAB)**  
2025 동계 특강 *"From Simulation to Reality: VLA 모델로 제어하는 로봇팔"* 실습 자료를 기반으로 제작되었습니다.

**LiDAR(Rangefinder) 센서와 Wheel Encoder 센서**를 이용해서 전방 장애물을 감지하고, 자동으로 회피 방향을 결정하는 **탐색 로봇 시뮬레이션**입니다.
LLM(Gemini)과 연동하여 사용자에게 직접 명령을 받아 로봇을 제어하며, MuJoCo 환경에서 자율 주행 및 탐색 동작을 실험합니다.

1. Gemini(LLM) 를 통해 "계속 직진"이라는 명령을 받으면, 로봇은 직진을 유지하며 지속적으로 앞 물체와의 거리를 측정합니다.
2. 전방 1m 이내에 장애물이 감지되면, 별도의 사용자 명령 없이도 직진을 멈추고 탐색 모드로 전환됩니다.
3. 탐색 모드에서는,
   - 오른쪽 60도 회전 후 전방 거리 측정  
   - 왼쪽 60도 회전 후 전방 거리 측정  
   - 측정된 거리를 비교하여 Turn Left / Turn Right / Back 중 하나의 행동을 선택합니다.
4. 회전 후 다시 직진을 계속합니다.

+ wheel encoder를 이용하여 바퀴의 회전량을 기반으로 몸체의 회전량을 구해 더 정밀한 회전 각도 제어가 가능합니다.
  카메라 입력을 기반으로 과일(사과,오렌지,바나나,수박) 이미지를 학습한 yolo 모델을 사용해 현재 보이는 과일이 무엇인지 구분 가능합니다.
